# Professional Portfolio

A modern personal portfolio website built with .NET to showcase my skills, projects, experience, and professional profile to recruiters and clients.

## Overview

This portfolio is designed to present my background as a .NET developer and DevOps professional, highlighting:

- Core technical skills and competencies
- Key projects and achievements
- Work experience and certifications
- Professional profile and contact information
- A clean, responsive design for desktop and mobile users

## Tech Stack

- ASP.NET Core
- C#
- .NET 8 / .NET 9 (depending on project configuration)
- HTML / CSS / JavaScript
- Bootstrap or Razor views for UI
- SQL Server / Azure services (if used in the project)

## Features

- Responsive portfolio landing page
- About section with bio and summary
- Skills and technologies timeline
- Project showcase cards
- Experience and education sections
- Contact form or direct contact links
- Professional branding and resume-ready presentation

## Getting Started

1. Clone the repository
2. Open the project in Visual Studio or VS Code
3. Restore NuGet packages
4. Update configuration files if needed
5. Run the application

```bash
dotnet restore
dotnet build
dotnet run
```
